# How to Run

1. Open project folder in VS Code
2. Make sure Java is installed
3. Open terminal
4. Compile the file:

  javac FileName.java

5. Run the program:

   
   java FileName
    
👉 Example:


javac StudentInheritanceDemo.java
java StudentInheritanceDemo
